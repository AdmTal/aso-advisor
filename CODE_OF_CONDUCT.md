# Code of conduct

## The short version

Be kind. Assume that the other person acts in good faith. Discuss the code and
the evidence, not the person.

## What we expect

- Give a correction with the reason and, where possible, with a source.
- Accept a correction with thanks.
- Respect that English is a second language for many readers and many
  contributors. Write simply.
- Respect that ASO has few certain facts. Say "I measured this" or "I believe
  this", and say which one it is.

## What is not acceptable

- Personal attacks, insults, and harassment.
- Sexual language or imagery.
- Publication of private information of another person.
- Advertising, or a pull request whose purpose is a link.

## Reporting

Report a problem to the maintainer through a GitHub issue, or privately through
the contact address on the GitHub profile of the maintainer. The maintainer
answers as fast as possible, keeps the report confidential, and can remove
comments, commits, issues, and contributors that break these rules.

This document adapts the ideas of the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
